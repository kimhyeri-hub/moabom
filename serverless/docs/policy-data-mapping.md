# 공개 지원정책 데이터 매핑

이 문서는 정부·지자체 공개 자료를 모아봄 지원금 모델에 넣기 위한 준비 상태입니다. 이번 작업에서는 외부 API를 호출하지 않았고, 파일을 대량으로 내려받지 않았습니다.

## 확인한 공개 경로

2026-11-04에 공공데이터포털 설명을 확인했습니다.

- 한국사회보장정보원 중앙부처 복지서비스 OpenAPI, 데이터 번호 15090532. 무료이고 이용허락 제한은 없으나, 활용신청과 인증키가 필요합니다. 키가 없으면 `SERVICE_KEY_IS_NULL`입니다. 개발계정 트래픽은 100건입니다.
- 지자체 복지서비스 OpenAPI, 데이터 번호 15108347. 같은 방식으로 인증키가 필요하고 개발계정 트래픽은 1,000건입니다.
- 보조금24와 정부24 공공서비스 OpenAPI도 공공데이터포털 활용신청 뒤 인증키를 씁니다.
- 복지서비스 정보 파일데이터는 서비스 ID, 서비스명, 서비스 URL, 요약, 소관부처, 기준연도, 최종수정일을 제공합니다. 공란은 빈 값이며 임의의 값을 채우지 말라고 적혀 있습니다. 행 수가 많아 이번 작업에서는 내려받지 않았습니다.

인증키가 저장소에 없으므로 목록 조회와 상세 조회는 다음 단계입니다.

## 필드 매핑

| 공개 항목 | 모아봄 필드 | 비어 있을 때 |
| --- | --- | --- |
| 서비스 ID | `sourceServiceId`, `grantId`는 `policy-`와 ID로 생성 | 저장하지 않음 |
| 서비스명 | `title` | 행 자체를 거절 |
| 서비스 요약 | `description` | null |
| 서비스 URL | `sourceUrl`, `link` | null |
| 최종수정일 | `referenceDate` (`yyyy-MM-dd`만) | null |
| 기준연도 등 원문 기준 | `referenceText` | null. 연도만 있을 때 1월 1일로 바꾸지 않음 |
| 신청 시작, 신청 마감 | `applicationStart`, `endDate` | null |
| 연령 하한·상한 | `minAge`, `maxAge` | null, 판정은 `UNKNOWN` |
| 지역 | `targetRegion` | null, 판정은 `UNKNOWN`. `전국`으로 시작하면 지역 제한 없음 |
| 소득분위 하한·상한 | `minIncomeBracket`, `maxIncomeBracket` | null, 판정은 `UNKNOWN` |
| 가구 코드 | `householdClarity`, `householdTypes` | 코드가 없으면 `UNKNOWN` |
| 특수조건 코드 | `specialClarity`, `specialConditions` | 코드가 없으면 `UNKNOWN` |
| 테스트 행 여부 | `sample` | 가상 8건은 true |

가구 코드는 `SINGLE`, `NEWLYWED`, `MULTI_CHILD`, `SINGLE_PARENT`입니다. 특수조건 코드는 `DISABLED`, `VETERAN`, `NEWLYWED`, `MULTI_CHILD`, `OTHER`입니다. 화면의 1인 가구, 신혼 부부, 다자녀, 한부모, 장애인, 국가유공자, 신혼, 기타와 대응합니다.

## 정규화와 중복

비교 전에 공백을 하나로 줄이고 유니코드 정규화를 합니다. 같은 `sourceServiceId`, 같은 출처 URL, 또는 같은 제목·지역·신청 기간이면 같은 정책으로 봅니다. 제목의 `[예시]` 접두만 비교에서 뺍니다. 자격 숫자는 원문에 없으면 만들지 않습니다.

## 지금 동작하는 범위와 다음 단계

가상 지원금 8건은 `local-grants.json`에 그대로 있고 `sample`이 true입니다. 가구 형태와 특수조건 필드를 적지 않은 가상 행은 그 두 조건을 제한 없음으로 읽습니다. 공개 정책 행은 해당 필드가 없으면 `UNKNOWN`이라 `CHECK_REQUIRED`가 됩니다.

구현된 것은 저장 필드, 매핑 함수, 중복 판별, 자격 판정, 화면 입력입니다. 인증키 발급, 실시간 수집, 운영 테이블 적재는 아직입니다.

## 제한 없음과 정보 없음

가구 형태와 특수조건의 `UNRESTRICTED`는 원문이 제한 없음이라고 밝힌 경우에만 저장합니다. 필드가 없거나 값을 해석할 수 없으면 `UNKNOWN`이며 자격 결과는 `CHECK_REQUIRED`입니다. 예시 지원금 8건은 카탈로그에 `UNRESTRICTED`를 직접 적어 두었고, 샘플 표시만으로 빈 값을 제한 없음으로 바꾸지 않습니다.

연령, 지역, 소득분위의 빈 값도 제한 없음이 아닙니다. 지역은 값이 `전국`으로 시작할 때만 제한 없음입니다.

## 로컬 입력

외부 API를 호출하지 않습니다. 로컬 API `POST /policies/import`가 JSON `records` 또는 CSV `content`를 받습니다. 필수값은 서비스 ID와 서비스명입니다. 기준일과 신청 기간은 `yyyy-MM-dd`만 저장하고, 연도만 있는 값은 1월 1일로 바꾸지 않습니다. 같은 서비스 ID, 같은 출처 URL, 또는 같은 제목·지역·신청 기간은 중복으로 보고 추가하지 않습니다. 예시 지원금 8건은 지우지 않습니다. `sample`이 없으면 공개 정책 입력으로 저장합니다.
